โครงการ: AIVA - AI Virtual Assistant (ระบบจัดการลูกค้าอัจฉริยะ)
ผู้พัฒนา: SpareX Co., Ltd.
วันที่: 8 มิถุนายน 2026

1. ข้อมูลความต้องการระบบ (REQUIREMENT TEXT)
--------------------------------------------------------------------------------
โครงการ AIVA คือแพลตฟอร์มระบบพนักงานขาย AI (AI Virtual Assistant) ที่ช่วยตอบแชทลูกค้า วิเคราะห์ข้อมูลลูกค้า และช่วยปิดการขายอัตโนมัติตลอด 24 ชั่วโมง โดยแบ่งความต้องการระบบออกเป็น 4 ส่วนหลักดังนี้:

   1.1 หน้าเว็บไซต์หลัก (AIVA Landing Page)
       - แสดงข้อมูลบริการ ฟีเจอร์หลัก (เช่น สอน AIVA, Inbox, Lead Capture, CEO Daily Report)
       - แสดงราคาแพ็กเกจ (Basic, Pro, Advanced) และรอบบิลการชำระเงิน (รายเดือน, 6 เดือน, รายปี)
       - มีระบบจำลองการชำระเงิน (Checkout Gateway) รองรับบัตรเครดิต, โมบายแบงกิ้ง และ PromptPay QR Code
       - ช่องทางติดต่อทีมขายสำหรับแพ็กเกจระดับสูง

   1.2 ระบบแพลตฟอร์มผู้ใช้งาน (AIVA Client Platform)
       - แดชบอร์ดภาพรวมสรุปจำนวนแชท อัตราการปิดการขาย และจำนวน Token ที่ใช้งาน
       - ระบบ "สอน AIVA" (Knowledge Base) สำหรับอัปโหลดไฟล์ PDF หรือลิงก์เว็บไซต์เพื่อฝึกฝน AI
       - หน้าแชทและอินบ็อกซ์จำลอง (AI Inbox & Chat) พร้อมการสลับเป็นระบบตอบมือ (Human Handoff)
       - ระบบ CRM Pipeline และข้อมูลลูกค้า (Leads)
       - ระบบการจัดการสาขา (Branches) และพนักงานในทีม (Team Management)

   1.3 ระบบพาร์ทเนอร์ตัวแทน (AIVA Partner Portal)
       - หน้าสมัครสมาชิกและเข้าสู่ระบบพาร์ทเนอร์/ตัวแทนแนะนำ (Sub-Partner)
       - แดชบอร์ดแสดงคอมมิชชัน ยอดขายสะสม และรายชื่อลูกค้าภายใต้เครือข่าย
       - ระบบสร้างลิงก์แนะนำ (Referral Code Link) สำหรับส่งให้ผู้ใช้งานสมัครบริการ
       - ระบบจัดการตัวแทนเครือข่ายย่อย (Sub-Partner Management)
       - ช่องทางพูดคุยช่วยเหลือกับทีมงานแอดมินกลาง (Super Admin)

   1.4 หน้าผู้ดูแลระบบสูงสุด (AIVA Super Admin Dashboard)
       - แดชบอร์ดสรุปผลการดำเนินงาน ยอดขายผ่านตัวแทน และอัตราคอมมิชชัน
       - การจัดการพาร์ทเนอร์ (Approve KYC, จัดการ Tier คอมมิชชัน)
       - ระบบส่งข้อความประกาศข่าวสาร (Broadcast Center) ไปยังพาร์ทเนอร์ทั้งหมด
       - ระบบรับแจ้งเรื่องเดือดร้อน (Support Tickets) ของพาร์ทเนอร์


2. รายละเอียดการติดตั้งและทดสอบระบบที่กำลังทำ (SYSTEM SETUP & INSTALLATION)
--------------------------------------------------------------------------------
เราได้ทำการดึงข้อมูลโค้ดจากเอกสาร `.docx` ทั้งหมด และจัดเตรียมสภาพแวดล้อมสำหรับการพัฒนา (Development Environment) ดังนี้:

   2.1 การเตรียมสภาพแวดล้อม (Installation & Scaffolding)
       - สร้างโปรเจกต์ React 19 บน Vite 8 และรันด้วย Node.js
       - ติดตั้งและตั้งค่า Tailwind CSS v4 สำหรับจัดการสไตล์ทั้งหมดของระบบ
       - ติดตั้งไลบรารี UI `lucide-react` สำหรับเรียกใช้ไอคอนแบบ Vector

   2.2 การผสานระบบและแก้ปัญหาความเข้ากันได้ (Integration & Compatibility)
       - ปรับปรุงและแปลงโค้ดหน้าเว็บ Landing Page จาก HTML ให้เป็น JSX Component ที่พร้อมใช้งานใน React
       - ย้ายระบบแดชบอร์ดทั้ง 3 (Client Platform, Partner Portal, Super Admin) เข้ามาอยู่ในโปรเจกต์เดียวกันในฐานะ Page Components
       - **แก้ไขข้อผิดพลาดทางเทคนิค (Syntax & Compatibility Errors):**
         * แก้ไขโครงสร้างคอมเมนต์ของ HTML (<!-- -->) ที่ยังค้างอยู่ในไฟล์ JSX ให้เป็น React Comments ({/* */})
         * แก้ไขไวยากรณ์ค่าหน่วยเวลาของ Style (เช่น animationDuration: 3s) ให้เป็นค่าแบบ String (เช่น '3s') เพื่อไม่ให้เกิด JavaScript Syntax Error
         * แก้ไขข้อผิดพลาดไอคอนแบรนด์ที่ไม่มีในระบบ (Facebook, Youtube, Instagram) โดยสร้าง React SVG Component ขึ้นมาทดแทน
         * แก้ไขไวยากรณ์ผิดพลาดของออบเจกต์จำลองในไฟล์แพลตฟอร์ม (icon: color: 'text-blue-500' -> icon: Facebook, color: 'text-blue-500')
       - สร้างโครงสร้างระบบการนำทางกลาง (State Routing) ในไฟล์ App.jsx พร้อมติดตั้งปุ่มเปลี่ยนหน้าเว็บจำลอง (Developer Portal Switcher) เพื่อช่วยให้ผู้ใช้สลับดูและตรวจสอบความถูกต้องของแต่ละหน้าจอได้ทันที

   2.3 การตรวจสอบความถูกต้อง (Verification)
       - ผ่านการทดสอบรันคำสั่ง `npm run build` เพื่อคอมไพล์โค้ด ผลลัพธ์สำเร็จลุล่วงแบบไม่มีข้อผิดพลาด (Zero Errors) พร้อมจัดทำไฟล์สำหรับการอัปโหลดโฮสทีงจริง (Production Bundles) เรียบร้อยแล้ว


3. ระยะเวลาการดำเนินงาน (PROJECT TIMELINE)
--------------------------------------------------------------------------------
รวมระยะเวลาจัดทำระบบต้นแบบหน้าบ้านจำลอง (Interactive Prototype): 5 วันทำการ
   - วันที่ 1: ติดตั้งโปรเจกต์และสร้างระบบสภาพแวดล้อมการรัน (Setup & Scaffolding)
   - วันที่ 2-3: แปลงโครงสร้าง Landing Page และ Dashboard จากไฟล์ต้นฉบับเป็น React Component
   - วันที่ 4: พัฒนาระบบนำทางสลับหน้าจอ (State Routing) และแถบเปลี่ยนหน้า Developer Switcher
   - วันที่ 5: ตรวจสอบจัดเตรียมระบบ จัดทำแพ็คเกจ และทดสอบรันสำเร็จสมบูรณ์ (Production Build)
